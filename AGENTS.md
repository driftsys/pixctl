# AGENTS.md

Instructions for AI coding agents working in this repository.

## Project

`pixctl` — fits raster images for Markdown docs and gates their display size.
Sibling of [`diagctl`](https://github.com/driftsys/diagctl). Scope: issue
[#1](https://github.com/driftsys/pixctl/issues/1).

Rust 2021, `clap` derive. Exit contract: `0` clean · `1` ≥1 check failed · `2`
operational error (each command maps its own errors to 2 and `main.rs` exits
with the code it returns).

## Modules

- `cli.rs` — `clap` definitions of the commands and their arguments.
- `contract.rs` — constants of the display contract (column, font, padding,
  frame, icon size) and its version.
- `convert.rs` — converts EMF and WMF files to PNG through Inkscape or
  LibreOffice, with a time limit.
- `load.rs` — decodes an image file to RGBA8 (EMF/WMF through `convert.rs`),
  detects transparent pixels and flattens an image to greyscale.
- `font.rs` — estimates the font size from the heights of the text lines.
- `rule.rs` — chooses the fit rule, scale factor and output width.
- `output.rs` — the JSON envelope, the coded `Failure` error, colour and counts.
- `inspect.rs` — the `inspect` command: builds the reports and prints them as
  plain lines or JSON.
- `checks.rs` — the four display checks (`width`, `min-font-size`, `opaque`,
  `framed`) on one decoded image.
- `check.rs` — the `check` command: runs the checks and prints PASS, FAIL and
  REVIEW lines or JSON.
- `fit.rs` — renders an image to the display contract and encodes the PNG or
  WebP.
- `fit_cmd.rs` — the `fit` command: writes one fitted PNG or WebP per input.
- `tests/fixtures/diagrams/` — public corpus of diagram images with exact
  font-size labels (`render.sh` regenerates it, `calibration/` checks the
  labels).
- `examples/eval/` — private Cargo example run by `just eval`: scores the font
  estimate on a labelled folder or surveys an unlabelled one, and prints totals
  only. Not part of the released binary.
- `main.rs` — thin glue: parses the arguments and calls the commands.

## Build commands

```bash
just            # list recipes
just fmt        # prim + cargo fmt, in place
just build      # full local gate (toolchain, prim, fmt, compile, test, clippy, shellcheck, install test)
just verify     # commit-message lint + full gate — run before opening a PR
just corpus  # re-render the diagram corpus (macOS, Homebrew tools); CI does not run it
just eval DIR [MANIFEST]  # private font-estimate evaluation of a folder outside the repo; totals only
just release    # git-std bump (changelog + tag) on a clean, CI-green main
```

`just test-converter` runs the ignored test that needs a real Inkscape, and
fails when it does not run; the `converter` CI job installs Inkscape and runs
it. The WMF fixture `tests/fixtures/rect.wmf` was built by hand from the WMF
specification (see the comment in `tests/convert.rs`).

CI (`.github/workflows/ci.yml`) runs only `just` recipes. Releases are built by
cargo-dist (`release.yml`) on a `v*` tag.

## Workflow

- `CHANGELOG.md` is generated by git-std. Never edit it by hand.
